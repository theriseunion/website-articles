# 喜报｜睿思智联中标国联民生AI算力调度平台开发项目

睿思智联 · 2026/05/19 10:20（北京时间） · [微信公众号原文](https://mp.weixin.qq.com/s/2OM7Zq4ZiXA_omTrE8yjiA)

近日，无锡产权交易所发布了“国联民生AI算力调度平台开发项目采购项目”中标结果，北京睿思智联科技有限公司凭借扎实的技术实力、成熟的项目经验与高质量的服务方案，成功成为该项目中标人。

近日，无锡产权交易所发布了“国联民生AI算力调度平台开发项目采购项目”中标结果，**北京睿思智联科技有限公司**凭借扎实的技术实力、成熟的项目经验与高质量的服务方案，成功成为该项目中标人。

![](./images/inline-01.png)

国联民生证券股份有限公司是国内领先的国有控股综合类上市券商，业务涵盖经纪、投行、资管等全链条金融服务。本次项目聚焦AI算力调度平台与模型推理服务建设，彰显了客户将AI大模型深度融入日常工作和核心业务的决心，以及对算力管理、平台化运营与技术落地能力的高度重视。睿思智联能够在激烈竞争中脱颖而出，不仅是对其算力调度与模型服务综合实力的充分肯定，更体现了客户对睿思智联在金融行业智算规划及落地交付经验的深度信赖。\

未来，睿思智联将秉持专业、高效、可靠的初心，严格扎实地推进项目后续工作，以高质量交付回馈客户信任。同时，睿思智联将以此次中标为新起点，持续发力核心技术创新，全面升级智算产品体系，为更多行业客户提供先进、稳定、可持续的AI平台解决方案，赋能更多行业客户构建大模型时代的核心竞争力。

### 关于睿思智联

北京睿思智联科技有限公司（RiseUnion）专注于AI 算力管理与调度，已完成 10+ 国产芯片兼容认证，是 CNCF Sandbox 开源项目 HAMi 的核心贡献者之一。公司是国家高新技术企业、北京市专精特新中小企业、AIIC 算力池化工作组组长单位，在金融、政企军工、交通、医疗等行业实现大规模生产级落地。

睿思智联致力于让算力像水电一样随取随用，为企业 AI 转型构建智能、可控、高效的算力底座。
