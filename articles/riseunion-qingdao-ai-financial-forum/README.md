# 睿思智联出席青岛AI金融论坛，引领金融智能化升级

睿思智联 · 2025/09/02 08:00（北京时间）

睿思智联受邀出席青岛银行'人工智能+金融青岛论坛'，展示异构算力融合平台在金融场景的创新应用，推动AI基础设施在智能投顾、风控合规等领域的落地。

![文章封面](./images/cover.jpg)

## 背景

近日，由“科创中国”金融科技服务团、中国通信学会金融科技专家委员会、中国互联网协会数字金融工作委员会联合青岛银行主办的 “科创中国”金融科技服务团走进青岛银行暨 **“人工智能 + 金融青岛论坛”** 成功举办。作为金融科技与人工智能深度融合的先行企业，**睿思智联** 受邀出席本次论坛，与来自政府机构、金融机构、科技企业及学术界的专家学者共商AI赋能金融的创新路径与实践方案。

本次论坛得到了山东省科学技术协会、青岛市科学技术学会、青岛东方数字普惠金融研究院等多方支持。会上，“科创中国”金融科技服务团专家工作站与“金科创新荟·金融科技工作者之家”青岛站正式揭牌，为区域金融科技创新搭建了技术交流、资源对接与成果转化的重要平台。睿思智联将依托这一国家级平台，深化与金融机构的技术协同与生态合作，加速AI能力在金融场景的落地与规模化应用。

## 引领金融 AI 智能化升级

论坛开幕致辞中，青岛银行党委书记、董事长景在伦指出，大模型为代表的人工智能技术正在深刻重塑金融服务模式，推动金融机构实现从“数字化”到“智能化”的跃迁。
> 科技赋能和产融协同，是把握新一轮金融科技机遇的关键
> -- 青岛银行党委书记、董事长景在伦

“科创中国”金融科技服务团团长杨竑及山东省科协二级巡视员葛玉芝等嘉宾一致认为，AI不仅提升金融服务效率，更是优化客户体验、增强风险防控、构建智慧运营体系的核心支撑。这与睿思智联始终坚持的“AI 驱动智能升级”理念高度契合，彰显了公司在金融科技创新方向上的前瞻布局。


## 金融级 AI 算力平台智能转型

在技术应用分享环节，睿思智联围绕**金融场景下的AI基础设施建设与创新实践**进行了演讲，展示了公司在算力平台领域的核心技术与落地成果。面对智能投顾、消费信贷、合规风控、知识管理及数据安全等金融细分场景，睿思智联自主研发的**异构算力融合平台**提供了从算力底座到业务调度的全链路支撑：

- **算力基础设施层：**统一接入英伟达、昇腾、昆仑芯、寒武纪多类型硬件GPU、NPU资源；
- **资源池化与虚拟化层：**实现算力资源精细化切分与弹性调度；
- **资源管理与调度层：**提供可视化监控、智能运维与成本优化能力；
- **调度器与设备插件层：**灵活适配不同AI框架与业务系统，实现高效协同。

该平台已在多家金融机构部署，显著提升模型训练效率与推理速度，为智能客服、反欺诈、信用评估等核心业务提供稳定可靠的底层支撑，实现“AI跑得更快、更稳、更安全”。

## 持续深耕，打造金融 AI 新生态

本次论坛不仅体现了睿思智联技术实力与行业影响力，也为公司拓展区域合作、链接优质生态资源提供了新机遇。未来，睿思智联将持续加大在**金融科技**领域的研发投入，依托“科创中国”金融科技服务团等平台资源，深化与青岛银行及行业伙伴的战略合作。同时，公司将开放更多技术能力，携手产业链上下游，共同探索AI在财富管理、绿色金融、普惠金融等新兴场景的创新应用，致力于成为金融机构最值得信赖的AI基础设施合作伙伴，引领金融智能化升级的新未来。
